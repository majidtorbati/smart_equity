# DATA_MODEL — فرمت فایل‌های ورودی

## ۱. فایل معاملات (مثل `book2.xlsx`)
شیت `Deals`، ۳۷ ستون. مهم‌ترین‌ها (نگاشت کامل در `app/data/import_engine.py:DEFAULT_COLUMN_MAP`):
نماد، شماره اعلامیه، تاریخ معامله (شمسی، فرمت رشته‌ای — جزئیات parse در `core/jalali.py`)، کد/شناسه ملی
خریدار و فروشنده، نام/نام‌خانوادگی خریدار و فروشنده، نوع خریدار/فروشنده، کدشسا خریدار/فروشنده، کد و نام
کارگزار خریدار/فروشنده، تعداد سهم، قیمت هر سهم.
نمونه فعلی: ۲۹٬۸۹۱ ردیف، نماد «آباد»، ۵٬۳۰۳ خریدار یکتا، ۲۰۳ کارگزار یکتا (تست‌شده در این نشست — Phase 0).

## ۲. فایل Registry سهامداران (مثل `900000.xlsx`) — ورودی جدید Phase 2
شیت با نام کد نماد (اینجا `900000`)، ۱۲ ستون:
```
شماره سهامدار | نام | نام خانوادگي | نام پدر | شماره شناسنامه_ثبت | محل صدور_ثبت |
كدبورس | كد ملي | تعداد سهم اول دوره | تعداد سهم خريداري شده | تعداد سهم فروخته شده | تعداد سهم پايان دوره
```
نکات:
- «كد ملي» بهترین کلید تطبیق با `persons.national_id` است (طبق قانون طلایی پروژه: کد ملی > نام).
- ستون‌های «خریداری‌شده/فروخته‌شده/پایان‌دوره» **مقادیر رسمی منبع بیرونی** هستند — برای Reconciliation
  با محاسبات خودمان (Ledger واقعی از روی `transactions`) مقایسه می‌شوند، نه اینکه مستقیماً به‌عنوان
  Purchases/Sales واقعی در FIFO استفاده شوند (FIFO باید از روی معاملات واقعی دانه‌به‌دانه محاسبه شود).
- طبق Master Prompt (بخش ۶): **فرض نکن نام ستون‌ها همیشه همین‌هاست** — Import Registry باید یک مرحله
  Column Mapping قابل‌ویرایش توسط کاربر داشته باشد (شبیه الگوی `DEFAULT_COLUMN_MAP` در import_engine.py
  فعلی، ولی با UI انتخاب ستون چون Registry فایل‌های مختلف ممکن است ساختار متفاوت داشته باشند).
- نام ستون‌ها معمولاً بدون نیم‌فاصله عربی/فارسی استاندارد است (مثلاً «شناسنامه _ثبت» با فاصله عجیب) —
  در Import باید strip/normalize شود، مثل الگوی `core/normalize.py` فعلی.

## اصل تطبیق هویت افراد (باید در کل پروژه یکسان بماند)
اولویت: `national_id` (کد ملی/شناسه) در صورت وجود و یکتا → در غیر این صورت `name_key` نرمال‌شده
(`identifier_confidence = 'low'`، طبق طراحی فعلی `persons` جدول). Registry هم باید از همین منطق match
با `persons` موجود استفاده کند، نه جدول افراد جداگانه بدون ارتباط.
