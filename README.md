# Smart Equity Transaction Intelligence

نسخه دسکتاپ پرتابل برای تحلیل معاملات سهام، رجیستری سهامداران، تطبیق مالکیت و FIFO.

## شروع کار

در اولین اجرای برنامه، ابتدا **فایل رجیستری سهامداران** و سپس **فایل خرید و فروش روزانه** درخواست می‌شود. رجیستری به‌عنوان مبنای اطلاعات اولیه مالکیت و FIFO وارد می‌شود.

برای شروع شرکت/نماد جدید، از دکمه **«پروژه جدید: رجیستری + معاملات»** استفاده کنید.

دیتابیس پروژه با بستن برنامه حذف نمی‌شود و کنار نسخه پرتابل باقی می‌ماند.

## خروجی‌ها

- PDF با فونت و RTL فارسی
- PowerPoint با تنظیم صریح فونت Latin / East Asia / Complex Script و RTL
- Excel با Sheetهای RTL، فیلتر، Freeze، قالب عددی و تنظیمات چاپ
- رجیستری و تطبیق هویت
- مالکیت و FIFO
- تحلیل‌های آماری معاملات و بازارگردان

## هوش مصنوعی

مسیر خودکار:

1. Ollama محلی، پیش‌فرض `qwen2.5-coder:7b`
2. سرویس OpenAI-compatible محلی در صورت تنظیم `SMART_EQUITY_LOCAL_AI_BASE_URL` و `SMART_EQUITY_LOCAL_AI_MODEL`
3. OpenAI اینترنتی در صورت وجود `OPENAI_API_KEY`
4. تحلیل داخلی SmartEquity بدون اینترنت و بدون مدل زبانی

کلید API داخل پروژه یا EXE ذخیره نمی‌شود. متن ارسالی به AI به‌صورت پیش‌فرض تجمیعی است و شناسه ملی/نام سهامداران را ارسال نمی‌کند.

## ساخت EXE پرتابل

روی Windows:

```bat
build.bat
```

نیاز ساخت: Python 3.12 x64. روی PC مقصد Python لازم نیست.

خروجی:

```text
dist\\SmartEquity\\SmartEquity.exe
```

کل پوشه `SmartEquity` را کپی کنید، نه فقط EXE را.
